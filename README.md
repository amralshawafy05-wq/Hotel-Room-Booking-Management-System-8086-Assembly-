# Hotel-Room-Booking-Management-System-8086-Assembly-
Hotel Room Booking System in Assembly (8086) نظام تفاعلي منخفض المستوى (Low-Level) لإدارة وحجز الغرف مُطور بلغة التجميع (8086 Assembly). يتيح النظام للمستخدم حجز الغرف، إلغاء الحجز، واستعراض حالة الغرفة (شغورها أو إشغالها) من خلال التعامل المباشر مع مقاطعات المعالج (BIOS/DOS Interrupts) وإدارة المصفوفات في الذاكرة.
